# マイク入力の中断と再接続

マイクトラックのended、または入力用AudioContextがrunningから外れた場合、入力処理を終了し、トラック・タイマー・イベント購読・コンテキストを解放する。マイク接続中の表示を解除し、入力中断のメッセージを表示する。手動停止は中断エラーにしない。

共奏／正しい音を待つモードでは伴奏を現在位置で停止する。お手本を聴くモードはマイクを必要としないため再生を継続する。再接続は「マイクで演奏する」、伴奏の再開は「演奏開始」で行う。再接続だけでは再生しない。

ブラウザ試験は合成音のMediaStreamを作り、トラック停止＋endedイベント、入力コンテキストのsuspendをそれぞれ再現する。表示解除、ピッチ表示のクリア、再生位置保持、再接続後の明示的な再生、手動停止時にエラーがないことを確認する。MacのWKWebView試験でも実物のマイクを要求しないMediaStreamを作り、切断表示と再接続可能なボタンへの復帰を確認する。

物理USB抜去、OSのマイク許可取消、Bluetooth切替の実機試験を代替するものではない。一時的なトラックmuteは切断扱いにしていない。マイクとMIDIを併用中でも、マイク切断時には入力依存の伴奏を止める。

MIDIでも選択中の機器が切断された場合に入力依存の伴奏を現在位置で停止します。他の機器の変更は停止理由にしません。切断・選択変更後に届いた古いコールバックは破棄します。再接続後は機器を選び直し、演奏開始を押します。ブラウザの偽MIDIポートとMacの仮想CoreMIDIソースで試験し、物理ClariMateの抜去は未検証です。

# 日英の練習導線と保存の確認

確認日: 2026-09-30。公開先へのアップロード・Appleへの公証提出・実楽器の奏者による観察試験は実施していない。

## 操作と表示

ホームから「自分のMusicXMLを開く」または2曲のサンプルへ進み、担当を確認して演奏する流れを日英対応にした。言語選択はこの端末に保存し、読み込み済みの楽譜や演奏中の音声を維持する。マイクなしの一定テンポと、マイク・MIDI接続中の状態を区別する。音符・小節へのキーボード入口は1つにし、矢印で小節移動、Enterで演奏・編集ができる。

テンポ・区間・表情の6つの基本操作を維持し、メニューから音量調整と小節の入り直しに進める。楽器配置、音色、メモ、A/B試聴、移調、練習履歴、実験的な表現プロファイルにも英語表示を追加した。譜面や奏者が入力した固有名・メモは翻訳しない。自然言語のリハーサル指示は日本語対応の機能として案内する。

MusicXMLの空ファイル・破損・形式不一致などを安定したエラーコードに分け、英語でも書き出し直し方を案内する。マイク非対応時は一定テンポやMIDIへ進める。音名メーターの連続読み上げを抑え、準備状態を通知する。

## 保存

- 同じ練習の保存を繰り返してもライブラリ項目を増やさず更新する。
- 保存待ち中に編集した場合、古い内容の保存完了を新しい編集の「保存済み」と表示しない。
- 停止後のメモ・テンポ・配置・伴奏設定を最近の練習へ反映する。演奏回数・時間・日付は増やさない。
- 停止直前の再開位置を保持し、350msの更新待ちより前にホームへ離れても最後のメモを反映する。
- 履歴の削除はその曲・担当の記録と再開用データを削除する。明示保存したマイ楽譜や、別の担当の履歴は保持する。削除後の遅い更新で履歴を復活させない。
- Mac版は起動時のローカル接続先を保存し、再起動で保存領域が変わることを防ぐ。競合時は別の保存領域へ切り替えず再試行を案内する。

旧開発版のランダムな接続先にある保存は自動移行しない。この修正によって既存の全保存領域を復元したという意味ではない。

初回の全ブラウザ試験では8件失敗した。5件はホーム導線と先頭selectに依存した旧テスト、1件はパート確認未完了で譜面表示領域が狭い状態でのスクロール判定だった。先頭2件は本番ビルドによるpublicファイル更新と開発サーバーの検証を同時に走らせた際にだけ読込状態が失われ、開発サーバー再読込の影響が疑われた。ビルドを先に完了し、適切な操作対象・初回確認に直した後、103件がすべて通過した。失敗した試験を除外して成功数にしていない。

native復旧試験ではWeb Contentの日本語表示名を認識できず一度中断した。実際の表示名を確認し、英語・日本語の完全一致を許可した。新規PID・bundle ID・所有グループ・一意性・終了直前の所有確認を維持したうえで復旧試験が成功した。

## 公開までに残ること

実楽器の追従・合奏感、初見の奏者による説明なしの開始と翌日の再利用は未確認。実ユーザーの人数は0人であり、合成音や自動操作の成功を代わりに数えない。

WebはHTTPS公開先・本番ルーティング・ホストのデータ処理と実在する窓口を確定する。Mac版はDeveloper ID署名、Hardened Runtime、公証・staple、別Macでの通常ダウンロードと更新を確認する。Intel版、macOS 13実機、物理MIDI、物理プリンターは今回の検証対象外。現在のアプリは開発署名版で、公証済みの一般配布版ではない。

具体的な配布順序は[公開準備計画](public-release-plan.md)、観察試験は[実楽器の初回試験](acoustic-first-use-test.md)、利用者向けの説明は[データの扱い](../public/privacy.html)を参照する。

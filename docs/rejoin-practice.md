# 合奏へ入り直す

楽譜ページ・準備ページの演奏操作に「この小節から入り直す」を追加。現在の再生小節の頭へ戻り、最低1小節のカウントインで再開する。2小節設定は維持する。別区間へループで戻らないよう、この操作ではループを解除する。音待ちモードでは表示しない。音声中断中は復旧操作を先に行う。

楽譜の音符を押す操作はその位置からの即時再生。途中で迷ったときは目的の小節を押し、「この小節から入り直す」で息を整えて入れる。推定位置による自動巻き戻しではなく、奏者が位置を決める。

`ConcertEngine.restartFrom` は古い発音・タイマー・追従状態を解放してから指定位置へ移動し、カウントインを開始する。演奏中の「この区間のお手本を聴く」「同じ区間を自分で吹く」もこの操作を使う。これまで演奏中の切り替えではseekがカウントを解除し、startが演奏中のため何もしなかった。

検証は、仮想時計での発音抑止・連打時のカウント再開始・不正位置の拒否、ブラウザの楽譜からの入り直し・カウント後の進行・停止によるキャンセル、Swift WKWebViewでの位置保持と再開を対象とする。演奏者が感じる入りやすさと実機の音の自然さは別途実演で評価する。

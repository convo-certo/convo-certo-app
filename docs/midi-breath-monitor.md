# ClariMateの息で試聴音を変える

「MIDI / ClariMate を使う」で機器を選び、「MIDI入力の試聴（電子音）」をONにする。発音中も、機器から届く息の値に応じて電子音の音量が変わる。機器自身の音を聴くときは試聴をOFFにする。

MIDIチャンネルごとにCC2を優先し、CC2をまだ受け取っていなければCC11を使う。どちらも来ていなければ、ノートオンのベロシティで鳴る。CC2とCC11を両方送る機器でも、二重に音量を掛け合わせない。CC2を一度受信したチャンネルでは、CC2=0の後にCC11が増えても音量はゼロのまま。再選択またはReset All Controllers（CC121）で優先状態をリセットできる。

息の値0〜127は入力専用のGainに0〜1で対応し、20msのランプでなじませる。試聴音は短いアタックとリリースの三角波系電子音。CCだけでは音を発生させず、ノートオン／オフで発音・離音する。クラリネットの生音再現、息による音色変化、ピッチベンド、サステインペダルは今回の機能に含めない。

チャンネルを維持してノートを受け渡し、別チャンネルの息を混ぜない。各チャンネル最大16声・最大16チャンネル。伴奏・クリックとは別の試聴用経路を使う。同じ音の重複したノートオンは直前の同音を離してから発音する。All Sound Off（CC120）とAll Notes Off（CC123）はそのチャンネルの試聴を停止する。試聴OFF、機器選択変更、入力切断、画面破棄では試聴用SynthとGainを破棄し、音を残さない。再びONにしても次のノートまで発音しない。

## 検証の範囲

Chromiumの実Web Audio出力をAnalyserNodeで測定する。伸ばした音について、CC11を127から32へ変えるとRMS振幅が約32/127になること、別チャンネルのCCで変わらないこと、CC2=0で消音しCC11より優先すること、CC121で復帰することを確認する。ノートオフ、重複ノートオン、CC123、試聴OFF/ON、切断と遅れて届く旧入力も対象。

Macの実WKWebViewではCoreMIDIの仮想送信元からノートとCCを送信し、試聴をONにしてCC11=32とCC2=0がWeb Audioのゲイン変更に届くことを確認する。Mac側の試験はゲインのスケジュール確認であり、物理スピーカー出力の測定ではない。

物理ClariMateの実演、機器の実設定別のCC送信、吹奏感の好みは未確認。息メーターの値だけから物理演奏の品質を判断しない。

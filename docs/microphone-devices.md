# 演奏に使うマイクを選ぶ

楽譜を開き、「あなたの楽器」の「使用するマイク」で入力機器を選んでから「マイクで演奏する」を押す。使用中は実際の入力トラックの機器名を表示する。機器名が取れない場合も、その旨を明示する。変更するときはマイクを停止してから選び直す。MIDI / ClariMateの選択とは独立している。

初回は権限のため機器名や一覧が制限される場合がある。その場合はシステム既定のマイクを一度開始して許可し、停止してから選ぶ。一覧だけの取得では音声入力を開始しない。開始成功後と機器の接続変更時に一覧を更新する。手動の「マイク一覧を更新」も使える。

選択した入力には `deviceId: { exact: ... }` を渡す。接続が切れて一覧から消えても選択を保持し、勝手に別の入力へ変更しない。選択中の機器を再取得できなければ接続と選び直しの案内を表示する。システム既定を明示的に選んだときはOSの既定入力を使う。一覧取得の失敗と入力自体の失敗は別に扱う。遅れて返る古い一覧で新しい一覧を上書きしない。

機器IDはその画面のメモリーだけに保持し、練習ファイルや保存済み楽譜に含めない。画面を開き直すとシステム既定になる。OSが既定入力を自動変更する場合まで固定する機能ではない。

## 検証

- Chromium: 初回許可後の一覧更新、音声出力を一覧に混ぜないこと、機器の厳密指定、使用中の表示と選択ロック。
- Chromium: 入力トラック切断→選択保持→指定入力の失敗→再接続。伴奏は明示的な再開まで止まる。
- Chromium: 一覧取得の競合と失敗からの再試行。許可準備をキャンセルした後に返るストリームは停止し、使用中表示にしない。
- macOS WKWebViewのsmoke: 擬似機器の一覧から選択し、getUserMediaの厳密指定を確認。実MediaStreamとAudioWorkletで4音の入力を処理。切断後の選択と表示を確認。

機器一覧とストリーム取得はテストで注入する。実USBマイクの抜き差し、OSの実許可ダイアログ、物理ClariMateの演奏精度をこれらのテストで証明したものではない。

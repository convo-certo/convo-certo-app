# 実楽器を使う初回利用の準備・確認 — 2026-09-25

**人による無説明の実演試験は0件。公開サイトからのダウンロード・初回インストールも未検証。** 以下は開発者による画面確認と人工信号を使う自動試験であり、奏者の成功率・音質の満足度・実楽器の追従精度の結果ではない。

参加者には [課題カード](acoustic-test-task.md) だけを渡す。[観察者用の手順と空欄の記録票](acoustic-first-use-test.md) は、操作案内として参加者に渡さない。実施相手についてユーザーへ確認中。募集連絡は送っていない。

## 見つけた問題と修正

| 開発者確認で見つけたこと | 修正 |
| --- | --- |
| マイクを接続しても音の到達を初回画面で確認できない | 初回パート選択に、一音チェックと入力音量・検出音を追加。接続成功と音の一致を分ける |
| 雑音と無音が同じ表示になる | 音程解析とは独立したRMSメーターを追加。雑音でも入力の到達を表示 |
| 移調楽器を使う設定が詳細画面に隠れている | 初回画面で実音／B♭／A／F／E♭／オクターブ移調を選択。楽器に合わせて伴奏を移調 |
| 初期例はA管や実音指定なので、手元の楽器と一致するとは限らない | 表示された最初の音とマイク入力を照合。一致が250ms継続したら準備確認とし、楽器・マイク・基準ピッチ変更時はリセット |
| Macアプリのマイク許可失敗にもブラウザの案内しかない | 許可拒否と機器・解析エラーを区別し、Mac／ブラウザの設定と再試行を案内 |
| 音声解析の90–1600Hz探索では低音を検出せず、高い音をオクターブ低く認識する例がある | 4096サンプル、探索40–2400Hzに変更。25ms更新を維持。範囲外の最初の音には対応範囲外と表示 |
| 文言がクラリネットや「吹く」に寄っている | マイク許可文と初回案内を楽器・演奏・鳴らす表現へ変更。管・弦・鍵盤の単音が対象で、和音と無音程打楽器は未対応と明記 |
| 演奏中というだけで「一緒に演奏中」と表示する | 「伴奏を演奏中」に変更。マイクの検出状態は別表示 |

ユーザーの最新指定に合わせ、休符上の追加数字と表示切替を削除した。元のMusicXMLの記譜、通常の小節番号、休符小節の再生位置ハイライトは維持する。

## 確認範囲

- 生楽器準備のブラウザ試験: ホームから収録曲を開く、マイク使用前は取得しない、B♭／A／実音の音高、無音・不一致・雑音、楽器変更とマイク再接続のリセット、許可拒否と再試行。入力は人工波形のMediaStreamを実際のAudioWorklet解析へ渡す。
- マイクの単体・統合試験: 22件通過。41.203–2093.005Hz、10音×2種類の倍音構成×44.1/48kHzの40条件で8cent未満。連続した同音の間の短い無音も確認。
- E1／C2／A4／C7の人工連続音による初回noteonは約125ms。従来の約75msから約50ms増加。OS・マイク・スピーカー入出力の遅延は含まない。解析単体の本機Node測定では最重のE1のp95が約0.98ms。実ブラウザの持続負荷や実演時の遅延を保証する測定ではない。
- 休符変更のブラウザ試験: 3件通過。追加数字なし、再生位置表示、狭い画面での表示を確認。
- Macアプリの現行画面を観察。参加者の初見評価ではない。

開発途中の18件同時確認は17件通過・1件失敗した。失敗時にPerformanceViewを編集中でViteのホットリロードが入りうる状態だったため、その実行を最終確認として使わない。失敗は表情試聴から演奏開始へ切り替える試験で、停止状態のままだった。コードを固定して再確認する。

その後、ビルドと同時に実行した21件の確認は、保存した楽譜の再読込で `Failed to fetch` が出て20件通過・1件失敗した。ビルドも停止してソースを固定した最終実行では **21件すべて通過（44.8秒）**。初回準備、マイク機器・切断復旧、休符表示、配置保存、表情試聴、練習再開を含む。先行する失敗を成功へ書き換えず、同時編集・ビルドを避けた実行を最終結果とする。型検査とWeb／Macビルドも通過。

MacのWKWebView確認は背面ウィンドウで全体60秒制限に達した。時刻付きログでは100msの待機が繰り返し約1秒になり、52.79秒でヘアピン確認に入り、60.99秒で全体制限に達していた。テストウィンドウを通常起動と同じ前面表示に変更し、60秒制限を延長せずに再確認したところ **全工程通過**。非永続ストレージと人工マイク入力は維持した。これは前面での確認であり、背面再生や人の実演の保証にはしない。

最終ブラウザログ・Macログ・携帯幅の画像は `verification-results/acoustic-first-use/` に保存。更新済みMacアプリは `build/native/ConvoCerto.app`。通常起動中のユーザーのアプリは強制終了していない。

## 実演で残る確認

実マイクの選択、ヘッドホンの発見、実音と記譜音、音色・音域・息や弓の立ち上がり、間違いからの復帰、長い休みからの入り、演奏中に手が塞がる状況、保存して翌日に戻れるかを観察する。低音域拡張の遅延が合奏感を損ねないかも確認する。5人に含まれなかった楽器・奏法を検証済みとはしない。

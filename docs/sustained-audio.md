# 管・弓奏の長い音を持続させる

収録MP3はデコード後約3.13秒で終わり、従来はそれより長い音符の途中で音源が無音になっていた。クラリネット・フルート・ホルン・弦など19種類の管・弓奏音について、音源の安定部分をループし、楽譜の音長と音量包絡に従って終了する処理を加えた。ピアノ、ハープ、ギター、チェンバロ、ティンパニ、グロッケン、マリンバは対象外。

デコード時に音源の約0.7秒地点と、約2.2〜2.32秒の候補区間の波形差を比較する。候補は4サンプルごと、比較は16サンプルごとに行う。選んだ末尾50msを前側の50msへ線形クロスフェードし、その先へループする。全チャンネルの接続に同じ位置を使う。元のMP3は変更しない。最初のアタックはそのまま保持する。1.5秒未満のサンプルは加工しない。

音長とピッチ変換後の再生速度から、ループ位置まで達する長い音にだけ加工済みバッファを使う。短い音は元のサンプルを使う。ループも通常の音量包絡・持続中の強弱・空間配置を通り、停止時には音源を切断する。追加バッファは読み込まれた対象音源ごとに保持するので、元のデコード済み音源に加えてメモリを使用する。

これは音を伸ばすサンプラー処理。呼吸・弓返し・音色の自然な変化を生成するものではなく、長く伸ばすと繰り返しや揺れが聴こえる可能性がある。各音域の聴感検査は未完了。出典と加工内容をクレジットに記載する。

ブラウザ試験では実クラリネットC4音源をWeb Audioで6秒間発音させ、4.2秒後の波形RMSが無音でないこと、停止後に無音になり音源が解放されることを確認する。冒頭0.5秒の一致、接続直前のサンプル値の一致、有限値、打楽器等の除外も確認する。Mac実WKWebViewでは長いクラリネット伴奏にループが指定され、その途中へ移動して再発音することを確認する。試験は物理スピーカー・聴感の検査ではない。

## 全音域の構造監査と無音サンプルの除外

`node scripts/audit-sustain.mjs [開発サーバーのURL]` は、起動済みの開発サーバー（省略時 http://localhost:5188/perform）を使い、19種類×C1〜C7の133ファイルを48kHzでデコードする。音源ハッシュを出典一覧と照合し、原音の冒頭0.5秒の保持、接続直前のサンプル値、有限値、100ms窓の最低RMSと持続区間平均RMSの比を記録する。比が0.05未満なら検査失敗にする。これは無音に近い区間の検出用閾値で、聴感品質の合格基準ではない。

初回 `sustain-2026-09-10T20-11-01.504Z` は11件で失敗した。元サンプルが完全無音だった: bassoon C7、contrabass C4〜C7、english_horn C7、tuba C6〜C7、alto_sax C7、baritone_sax C6〜C7。加工による無音ではなかった。

音源準備で全チャンネルを検査し、振幅0.000001を超える有限値がないサンプルを選択候補から除外する。以後は音のある最寄りのC音源を移調する。1つの楽器で有効な音源が0件なら準備を失敗として知らせ、無音のまま演奏可能にはしない。元MP3と出典一覧は保持する。自然な演奏音域の宣言や高品質な音域拡張ではなく、大きな移調では音色が変わる。

修正後は133件中11件を明示して除外し、有効122件の検査が通過した。最低100ms窓/平均RMS比は約0.322、接続直前の値の不一致は0。対象外の7種類の減衰音源の持続性はこの監査に含めない。ブラウザ試験ではコントラバスC4に対してC3由来のバッファが選ばれることと、全音源が無音の場合の失敗・再試行も確認する。

## 試聴用A/Bセット

`node scripts/render-sustain-comparison.mjs [開発画面のURL]` は、起動済み開発サーバー経由で実装を読み込み、クラリネット・弦アンサンブル・ホルンのC4を元処理/持続処理でレンダリングする。各6秒、同じゲイン0.5と120msリリース、48kHzステレオPCM。空間処理と追従は含めない。各ペアのA/B順序をランダムにし、ローカルHTMLに比較音声と任意の感想欄を付ける。元音源が途中で終わる違いは隠せないため、厳密な盲検の研究デザインとはしない。

生成例: `verification-results/listening-2026-09-10T20-17-55.443Z/index.html`。`report.json` に元MP3、実装、生成WAVのハッシュ、ピークと後半・終了後RMS、A/B対応を記録する。回答JSONは比較レポートのSHA-256を参照し、別セットの回答と混同しない。回答は未選択から始まり、手動保存のみ。収集・送信は実装しない。

6ファイルのブラウザデコード、別の音声を再生すると先の音を止めること、回答の書き出し、未回答の保持、390pxでの表示を確認した。試験入力はユーザーの聴感評価として保存していない。作成しただけでは自然さや好みの証拠にならず、実際の回答は未取得。

# 追加収録と楽器入力（2026-09-09）

MusicXMLは既存4譜から30譜へ拡充。`public/repertoire/ensemble/catalog.json` が検索用一覧、`sources.json` が出典・PDMX行・ファイルハッシュ・権利表示の確認記録。曲数ではなくファイル数を数える。編曲や楽章単位のものを含む。

追加した管弦楽の特集5譜は、ドヴォルザーク交響曲第9番第2楽章、モーツァルト交響曲第40番第1楽章、チャイコフスキー交響曲第4番第4楽章・第6番終楽章・《くるみ割り人形》雪片のワルツ。木管・金管・弦のパート構成を確認した版。元の出版譜との全音符の校合は未実施。

《フィンガルの洞窟》《シェヘラザード》第2部などの候補には吹奏楽編曲が含まれていたため、管弦楽総譜としては収録していない。クラリネットの有名ソロを含む楽章の優先収集は継続課題。ベートーヴェンの希望は **ピアノ協奏曲第1番第2楽章**。従来収録した第5番を代替として扱わない。第1番の再配布可能なMusicXML総譜は未確保。

ベートーヴェン交響曲第7番 Op.92も再調査したが、取得できたMusicXMLは第2楽章のピアノ版、ファゴット三重奏、単一楽器の抜粋などで、交響曲の合奏用総譜ではなかった。作品名の検索結果だけでは収録済みとせず、編成済みMusicXMLを取得して全パートを検証できるまで未確保状態を維持する。

ベートーヴェン《ピアノ協奏曲第1番》第2楽章もScoreBaseで再検索したが、該当するMusicXML総譜は見つからなかった。第5番の収録を第1番の代替とはせず、公開初版または権利確認済みの編成済みMusicXMLを取得するまで未確保として扱う。

PDMXメタデータの `cc-zero`、`license_conflict=False`、非ペイウォール、有効ファイルに加え、MusicXML内部の権利表示を確認。現代の映画・ゲーム曲など、原曲自体の権利が不明な候補は、CC0表示だけを根拠に採用していない。これは出版社・作曲者による保証や個別の法的判定ではない。

## 楽器選択

MusicXMLに存在する任意のパート・識別された声部を選べる。移調はA/B♭/F/E♭管、オクターブ移調、譜面固有の指定に対応。席変更時は原調へ戻し、その席の移調を使う。34種類のサンプル音源を用意し、出典・ハッシュは `public/audio/fluid/sources.json` に記録。無音程の打楽器の入力追従は未対応。マイクは単音向けで、ピアノなどの和音入力にはMIDIを使う。

## ClariMate

公式アプリが作る **ClariMate MIDI Out** をConvoCertoの「ClariMate / MIDIを接続」から選ぶ。自動選択・受信した記譜音/実音/強さ・電子音モニターを用意。切断時は機器選択を解除する。

公式アプリの本体音源の移調とMIDI移調は別設定。MIDI移調0なら、ConvoCerto側のMIDI音高を「記譜音」にし、使用楽器を正しく指定する。公式アプリがすでに実音へ移調していれば、ConvoCerto側は「実音」にする。二重移調を避ける。

Playingモードは演奏向け、Notationモードには40msのフィルター遅延がある。ClariMateの標準velocityは80固定。現状のConvoCertoで音の強さを反映したい場合は公式アプリのDynamic velocityを使う。息の連続CCやピッチベンドによる音源制御は未実装。

## 譜面の操作

描画と再生位置の更新を分離し、現在の音符・休符を着色。次の音への先走りと先頭への反復リセットを廃止。スクロールは現在位置が譜面領域の外に出たときだけ領域内で移動し、ページ全体をスクロールさせない。音符・休符のクリックまたはEnter/Spaceで、その位置から再生する。反復中のクリックは現在の周回を優先し、共奏画面では既存ループを解除する。

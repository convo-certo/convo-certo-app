# 相手を聴いてから自分の入りへ

「お手本と吹き比べる」内に「入りの1小節前から合わせる」を追加した。MusicXMLで選んだ席の最初の音を探し、その音を含む小節の1小節前から、入りを含む4小節の終わりまでをループする。冒頭から入る席では前の小節がないため無効にする。

最初に1小節のカウントインを行い、その後に実際の伴奏を1小節聴いて入る。自分の席は伴奏から除く。同じMusicXMLパートに第1・第2声部がある場合も、選んだ声部だけを空けて相手を残す。自動的に第2声部を推測して選ぶ機能ではないため、先に「あなたが入る席」で担当を選ぶ。

「この区間のお手本を聴く」「同じ区間を自分で吹く」を使っても前の1小節を含む区間を保つ。既存の「この練習を保存」や練習ファイルの開始・終了小節として保存できる。通常の「自分の入りから吹く」の区間は変更しない。

曲頭ではない最初の入りを対象とし、現在位置以降のすべての入りを一覧化する機能ではない。区間はリピート展開後の再生小節で選ぶ。事前に指定した合図待ちやミュートは維持されるので、相手が必ず途切れず鳴るという保証ではない。

ブラウザ試験では、自作の2声部MusicXMLを使用。第1声部はG3を吹き続け、第2声部は2小節休んでC4から入る。第2声部を選ぶと開始2・終了6小節になること、実Web Audioの音源開始が入りの前後とも第1声部の音高だけであること、冒頭から音がある全パートへ選び直すとボタンが無効になることを確認した。初回の試験は最寄りサンプルのルートに対するテスト側の想定を誤って失敗し、C4からG3への再生速度に修正して通過した。

これは実演の聴きやすさや初回利用者の操作成功率を測ったものではない。次の比較では、通常の小節指定に対して「相手を聴いて第2奏者として入る」準備時間・操作数・補助の必要性を測る。

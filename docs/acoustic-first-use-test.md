# 実楽器で、説明なしに最初の練習を始められるか

状態: **実施準備。人によるセッションは未実施、募集・連絡は未送信。** この文書や自動操作の結果を、実演で成功した証拠にはしない。

[初回観察試験](pilot-session.md)を、異なる実楽器を演奏する初見の人の短い試験にする。[発売判断の証拠監査](launch-evidence-audit.md)で未確認だった「初回の共奏」と「次回の再開」を観察する。まず5人、1人25〜30分。5人の結果は改善箇所を見つける材料であり、市場全体の成功率や発売の合否へ換算しない。

## 用意するもの

- 初めて使う奏者5人。できるだけ、C管の木管（フルート・オーボエ等）、B♭管（トランペット・クラリネット等）、F管またはE♭管（ホルン・アルトサックス等）、擦弦楽器（バイオリン等）、低音楽器（ファゴット・トロンボーン・チェロ等）から各1人にする。集まった楽器と音域を記録し、未参加の楽器まで対応確認済みとはしない。開発者や既に操作を習った人の結果は別にする。
- 本人の楽器、普段練習するMacと音声出力。ヘッドホンは利用できるようにしておくが、初回は観察者から接続を教えない。Bluetoothか有線かも残す。
- 同じ版のアプリと配布URL。公開サイトが未完成なら、実際に使った開始地点を「ローカルのアプリ」などと明記し、ダウンロードからの検証済みとはしない。署名・公証の不足を手動で回避した場合も支援として残す。
- 本人が演奏できる短い区間。同梱曲を使うか、本人が用意したMusicXMLを使う。持ち込み譜面は事前に別環境で音符・移調・担当を確認し、参加者のMacに設定済みの練習状態を作らない。未確認の譜面なら探索として区別する。
- 下の観察票と時計。アカウント、MIDI機器、ClariMateは参加条件にしない。

冒頭には「演奏の上手さではなくアプリを調べます。いつでも中断できます」とだけ伝える。操作動画や画面の説明は見せない。画面・音声の録画は初期状態では行わず、必要な場合は用途・保存先・削除日を示して別に同意を得る。演奏中に考えを話し続けてもらわない。

## 参加者に渡す依頼は一つ

> このアプリを使って、ご自分の楽器で曲の一節を伴奏と演奏して、練習してください。今日は納得できるところまで試して、また次の練習で続きをできるようにしてください。

曲の候補やファイルが必要な場合は用意したものを渡すが、押すボタン、マイクの設定、保存方法は教えない。アプリ内に表示される案内は本人が自由に読んでよい。

## 当日の進め方

| 場面 | 観察者がすること |
| --- | --- |
| 開始 | 配布URLを渡した時刻を記録する。アプリ起動時刻も別に記録する。インストール済みならそこから始めたと明記する。 |
| 最初の練習・約10分 | 口を挟まず、操作、迷った画面、演奏し始めた時刻、止まった理由を短く書く。5分経過時点の到達状態も記録するが、本人へカウントダウンしない。 |
| 繰り返し・終了まで約10分 | 同じ区間をもう一度演奏する、止める、再開する、長い休みから入る、設定を残す等が自然に起きるかを見る。まだ使っていない機能を試すよう誘導しない。 |
| 終了後・約5分 | 「どこで迷ったか」「伴奏は何に合わせて動くと思ったか」「演奏しやすかった／しにくかった箇所」「次はいつ何を練習するか」を尋ねる。観察が終わってから必要な操作を説明する。 |

操作を尋ねられたら、まず「普段ひとりで使っているとしたら、どうしますか」と一度だけ返す。本人が支援を求め続ける、やめたいと言う、または同じ箇所で約2分進めなくなった場合は、その時点までを**支援なしでは未到達**として記録し、続けたい場合だけ最小限の支援をする。以後の成功は支援ありとして区別する。音量の不快感や機器の異常があれば即座に止める。

## 「音が出た」から分けて見ること

- **開始できた:** 自分の担当を選び、伴奏と一節を最後まで演奏できた。区間と演奏時間を残し、約60秒続いたかも記録する。短い曲を60秒へ引き延ばす必要はない。
- **意図した動きだった:** 自分の担当が伴奏に重ならず、記譜音と実音が楽器に合っていた。一定テンポで練習したのか、マイクで追従させたつもりなのかを本人の発言と画面状態で分ける。マイク未接続のまま演奏できても、追従成功とはしない。
- **音声入力が使えた:** マイク許可画面に気づいたか、拒否・保留から戻れたか、意図したマイクを選べたか。メーターだけで正しい追従と判定せず、実際に演奏した音・譜面位置・伴奏の動きを照合する。生音声を保存しない場合は観察できなかった内容を空欄にする。
- **演奏しながら使えた:** 両手が塞がった状態で入りがわかったか。伴奏音と自分の生音の聞こえ方、ヘッドホン装着の発見、無線出力の遅れ、伴奏のマイクへの回り込み、息継ぎや弓の返し・間違い・長い休符からの復帰を記録する。観察のためにわざと難しい奏法をさせない。
- **続けられた:** 自力でもう一度練習し、終了後に同じ曲・担当・区間へ戻れたか。好意的な感想や「また使いたい」は、実際の再利用と別にする。

現行のマイク追従は単音が対象。ピアノの和音や弦の重音、無音程打楽器に同じ追従ができると本人が受け取っていないか、画面の説明から制限に気づけるかも観察する。これらを5人の演奏課題へ無理に足さず、該当する奏者や譜面で起きた場合に記録する。MIDIへの変更や単音化で続行できても、元の実楽器・奏法で成功した結果に置き換えない。

不具合は「どの操作・小節・音域で」「本人は何を期待したか」「何が起きたか」で記録する。未確認の低音・高音や楽器特有の音色で認識できない場合は、アプリの適用範囲の問題として残す。移調や譜面の問題も奏者の技能不足として扱わない。改善後の再試行は同じ人の学習済みの結果であり、初見成功へ書き換えない。

## 翌日の確認

初回の終わりに、翌日一度だけ確認してよいかと連絡方法を本人に尋ねる。連絡は別途、宛先と送信の許可が揃ってから行う。実際に送る前に内容を確定する。

聞く内容は「昨日のあと、自分からもう一度使ったか。使ったなら何を練習したか、前回の続きに戻れたか。使わなかったなら、練習の予定がなかったのか、使う理由がなかったのか、困って開けなかったのか」。確認連絡より前の利用と、連絡を受けてから試した利用を分ける。翌日に練習予定がなければ未評価とし、失敗扱いしない。ログの提出は任意で、個人の楽譜や生音声を自動送信する前提にしない。

## 5人を見たあと

人数と各人の到達状況をそのまま並べ、演奏を始められなかった原因と、演奏を続けられなかった原因を優先して直す。同じ失敗が何人に起きたか、1人だけでも練習不能になった問題があるかを見る。次の初見の人で修正後を確かめる。未観察の楽器・機器・翌日利用は未確認のまま残す。

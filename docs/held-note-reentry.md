# 持続音の途中から再開する

小節・演奏位置を選び直したとき、移動先をまたぐ伴奏音の残りを発音する。以前は移動先以降に開始する音符だけを予約していたため、タイ等で長く伸ばしている音が抜けていた。合図待ちを解除するときも、待ち位置をまたぐ音を戻す。カウントインや合図待ちの間は発音しない。

元の音符は変更せず、残りの記譜音長とアーティキュレーションの残りを作る。MusicXMLの強弱曲線は移動位置の音量で開始し、その先の曲線を相対位置へ変換する。開始位置が移動先と同じ音は通常の予約だけで発音し、二重に鳴らさない。すでに記譜上のゲートが終わった音は復活させない。担当パートを伴奏から除く既存の選択を維持する。

サンプルは新たなアタックから再発音する。録音の途中へのシークや、発音済みの音源の位相を保った復元ではない。以前の瞬間の奏者反応や表現によるゲート短縮を記録して復元する機能でもなく、再開時の表現設定を適用する。自然な合奏への戻り方は実演で評価が必要。

単体試験で強弱曲線・残りの音長・終了済みの音・カウントイン・重複発音防止・停止時の破棄を確認する。ブラウザ試験では1つの長い音の途中へ移動し、実Web Audioの発音が1回増え、その後重複しないことを確認する。Macの実WKWebViewでは2声のクラリネット譜の途中へ移動し、残された伴奏声部が再発音することを確認する。
